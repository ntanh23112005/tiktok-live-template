## HƯỚNG DẪN SET-UP TOOLS + LIVE
- **Với tài khoản Tik Tok đã có quyền Live + Đã có đủ Các thứ cần có để chạy tools ở trên:**
  - **Đối với máy Windows:**
    - **Step 1:** Chạy tools lên bằng file Batch để sẵn trong source -> Sẽ hiện lên cửa sổ terminal
    - **Step 2:** Nếu terminal đã cho bạn đường dẫn của tool (Ví dụ: http://127.0.0.1:3000/admin, [http://127.0.0.1:3000/overplay](http://127.0.0.1:3000/admin, http://127.0.0.1:3000/overplay)). Thì bạn có thể mở google với đường dẫn để vào giao diện quản lý
      - **Giải thích:** http://127.0.0.1:3000/admin, http://127.0.0.1:3000/overplay : 127.0.0.1 là môi trường tools chạy trên máy bạn, chỉ có thể mở bằng máy của bạn -> Không có nghĩa là bạn chạy tools bằng máy của bạn lấy máy khác mở đường dẫn
    - **Step 3:**
      - **Live bằng Tik Tok Studio:** Mở Tik Tok Studio -> Add Source Live -> Chọn " Nguồn màn hình (Display capture / Window capture) " -> Thêm đường dẫn (ví dụ lúc chạy tool để là: http://127.0.0.1:3000/overplay) -> Điền vào ô source là http://127.0.0.1:3000/overplay#tiktol.studio để tiktok studio hiểu đường dẫn -> Kiểm tra thật kĩ các tính năng trước khi bấm bắt đầu Live
      - **Live bằng OBS:** Liên hệ facebook: https://facebook.com/ntanh23112005 để nhận hướng dẫn cách lấy **Tiktok Stream Key cho OBS** _(BÉ XIN TÍ NƯỚC LỌC)_

  - **Đối với máy MacOS:**
    - Hãy sử dụng AI để viết ra 1 file Batch chạy như của windows và làm tương tự
