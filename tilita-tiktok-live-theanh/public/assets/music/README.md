# Nhạc nền

Đặt file MP3, WAV, M4A hoặc OGG vào thư mục này, rồi bấm **Cập nhật danh sách nhạc** trong admin. Chọn bài để phát và lưu ngay, âm lượng tiếp tục dùng mức % đã đặt.

Tên file được dùng làm tên bài nếu chưa có nhãn trong `config/music.json`. Hỗ trợ chữ tiếng Việt, khoảng trắng, dấu gạch nối và ngoặc đơn. Các file nằm trực tiếp trong thư mục này được quét tự động, không quét thư mục con.

Ba bản không lời Sen tĩnh, Trúc an, Mây thiền được tạo riêng cho Tâm an lạc; mỗi bản dài 3 phút 12 giây và phát lặp. Bản Niệm Phật phối khí được sao chép từ file đã có trên máy. Xem `THIRD-PARTY.md` để biết nguồn nhạc.
